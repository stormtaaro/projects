# Announcement Ticker

This example shows how to display announcements from a SharePoint list on a page.
Embed the HTML from `ticker.html` in a Script Editor or Embed web part.

## Usage
1. Ensure your site contains a list named **Announcements** with items that have the *Title* field.
2. Copy the contents of `ticker.html` into a Script Editor web part on your SharePoint page.
3. Save and publish the page. The web part will fetch the latest 5 announcements and show them as a list.
